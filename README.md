## Featured GenAI project

### PaperMind — Agentic RAG Research Assistant

PaperMind is a research assistant for chatting with PDFs, text, Markdown, web pages, and arXiv papers. It routes each question between indexed-document retrieval, live web research, claim verification, and direct answers—then shows the evidence path behind the response.

Key capabilities:

- Agentic routing with LangGraph
- Grounded answers with visible citations
- Qdrant-based semantic retrieval using BGE embeddings
- Live web and arXiv research with Tavily
- Relevance grading and query rewriting
- Claim verification against current sources
- Streaming responses and conversation memory
- DeepEval-based RAG evaluation
- Private browser-scoped workspaces and prompt-injection safeguards

**[View the public showcase](https://github.com/AkashhDixit/PaperMind-Showcase)** · **[Try the live app](https://papermind-ybhjwaq8v7pjh4yc3cc2gd.streamlit.app/)**
